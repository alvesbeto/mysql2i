# SDD templates

## prd.md (minimal)

```markdown
# PRD: <title>

## Objective
## Scope / out of scope
## Consumer impact (Webcred, semver)
## Success criteria (testable)
## Boundaries (always / ask / never)
## Open questions
```

## techspec.md (minimal)

```markdown
# TechSpec: <title>

## Components and files
## Implementation order
## Contracts (signatures, semantics)
## Reuse search (what exists, decision)
## Risks
## Out of scope
```

## tasks.md

```markdown
- [ ] Task …
  - Acceptance: …
  - Verify: …
  - Files: …
```

Promote behavior to [../../specs/shim-behavior.md](../../specs/shim-behavior.md) when the feature ships.
